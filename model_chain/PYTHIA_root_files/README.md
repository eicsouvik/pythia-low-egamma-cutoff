The weighted PYTHIA analysis output used by this model chain is:

```text

```

It is generated by `scripts/run_chain.sh` from
`macros/11_13_2026/analysis.cxx` using the representative n00n weight table at
the package root. The reference file has:

```text
size:   620,562,128 bytes (approximately 592 MiB)
SHA256: 133a9f43d11e6e2ec9efddb05c87e8213308b892d54f12730a004b45e7030b50
```

The ROOT file is intentionally not stored as an ordinary Git blob because it
exceeds GitHub's 100 MB per-file limit. Copy an existing reference production
to the path above, or generate it by running the documented chain. The
directory's `.root` files are ignored by Git.
